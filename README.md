# 🪷 Ragani & Pranay - Wedding Celebration Hub
### Dual-Destination Wedding Invitation (Pratapgarh ↔ Hyderabad)

## 📁 What is in this folder:
- **`index.html`**: The complete wedding website. Double-click to open in any web browser!
- **`assets/`**: Contains all high-resolution ceremony photos, card cover, and the background video (`hero-video.mp4`).
- **`vercel.json`**: Pre-configured configuration file for 1-click deployment on [Vercel](https://vercel.com).
- **`package.json`**: Standard project metadata.

---

## 🚀 How to View Locally:
Just double-click on `index.html`. It works instantly in Chrome, Edge, Safari, or Firefox without requiring any internet server.

---

## 🌐 How to Update your Vercel Link:
1. Log in to your [Vercel Dashboard](https://vercel.com).
2. Go to your existing project or create a new one.
3. Replace the files with the contents of this folder (or push to your connected GitHub repository).
4. Vercel will immediately deploy the new design live!
